CyberLab no Windows

Entenda o comando antes de executar.

Comece por navegar nas pastas, ler arquivos e observar seu computador. Depois use essa base para estudar rede, registros de atividade e integridade.

Escolha seu terminal abaixo. Os exemplos são para Windows 10 e 11, com Windows PowerShell 5.1 ou PowerShell 7 no Windows. Copie o comando e execute no seu terminal. Esta página não executa comandos no computador.

Como abrir o laboratório

Extraia o ZIP do GitHub. Abra index.html para as aulas ou dê dois cliques em iniciar.cmd para iniciar o servidor e abrir o navegador. O servidor precisa de Python 3.10 ou superior.

No CMD, execute iniciar.cmd. No PowerShell, execute .\iniciar.cmd. Há também .\iniciar.ps1 quando a política de scripts permitir. Se ela bloquear o arquivo, use o .cmd ou py -3 lab.py --open.

Mantenha o terminal aberto durante o uso do servidor. Pressione Ctrl+C para encerrar. O endereço é http://127.0.0.1:8000; 127.0.0.1 significa este computador.

Três práticas curtas

Use os passos do terminal selecionado. Rode uma linha por vez. A pasta de treino fica nos arquivos temporários do seu usuário e pode ser removida pelo Windows depois.

1 · Criar, ler e copiar um arquivo

Crie uma pasta de treino e um arquivo com uma anotação. > e Set-Content substituem o conteúdo de um arquivo existente; use apenas este arquivo de exercício.

Confira: a pasta deve conter nota.txt e copia.txt. A cópia neste mesmo disco é só uma demonstração, sem proteção contra falha do aparelho.

2 · Ver uma alteração pelo hash

Continue na pasta da prática 1. Calcule o hash, acrescente texto à nota e calcule de novo.

Confira: o hash da nota muda. O da cópia continua com o valor anterior. Hash ajuda a comparar conteúdo, mas não cifra o arquivo nem atesta que ele é seguro.

3 · Ler os registros do CyberLab

Abra outro terminal na pasta do projeto. Use o arquivo fictício exemplos\acessos.log que acompanha o CyberLab.

Confira: aparecem três linhas com status=401. O IP 203.0.113.42 também aparece depois com sucesso e download de backup. Isso merece investigação; esses registros isolados não identificam a pessoa nem provam uma invasão. Os IPs desse arquivo são exemplos reservados para documentação.

Conecte os comandos às aulas

Confidencialidade: observe quem tem permissão de acesso. Integridade: compare hashes antes e depois de uma alteração. Disponibilidade: teste o servidor local e pratique recuperar cópias.

Autenticação confere a identidade; autorização define o que essa conta pode fazer. whoami mostra a conta da sessão, sem testar uma senha.

Validação: no seu código, confira tipo, tamanho e intervalo de entrada. Logs: descreva o que o arquivo registra antes de concluir a causa.
